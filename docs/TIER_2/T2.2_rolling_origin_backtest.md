# T2.2 — Rolling-origin backtest across winters

**Goal:** show the 24h model's skill is not an artefact of the single
Nov–Dec 2025 test window.
**Status:** complete.

## What was built

`src/evaluation/rolling_origin_backtest.py` runs an expanding-window
(rolling-origin) backtest with the frozen model architecture (50/50 blend of
persistence and Ridge α=1000 on the 49-feature curated set). Only the training
cut-off moves.

| Fold | Train window | Test window | Test label source |
| :--- | :--- | :--- | :--- |
| `winter_2024` | 2024-01-01 .. 2024-10-31 | 2024-11-01 .. 2024-12-31 | CPCB-recomputed |
| `winter_2025` | 2024-01-01 .. 2025-10-31 | 2025-11-01 .. 2025-12-31 | official |

## Result

Output: `reports/modeling/24h/rolling_origin_backtest.csv` / `.md`.

| Fold | Train n | Test n | Hybrid MAE | Persistence MAE | MAE skill | MAE-skill 95% CI | RMSE skill |
| :--- | ---: | ---: | ---: | ---: | ---: | :---: | ---: |
| winter_2024 | 47,687 | 10,066 | 36.97 | 41.05 | +0.0994 | [+0.059, +0.138] | +0.0961 |
| winter_2025 | 103,703 | 9,800 | 34.07 | 38.34 | +0.1114 | [+0.077, +0.145] | +0.1181 |

**Mean MAE skill: +0.1054 ± 0.0060**
**Mean RMSE skill: +0.1071 ± 0.0110**

The model beats persistence on both metrics in both winters, and the day-block bootstrap CI
of the MAE skill excludes zero in each fold. That is a real, if modest (~10-11%), edge.
Training rows in the 24h before each test window are dropped (24h embargo; their `t+24` labels
would fall inside the test window). This changed the skill by <0.001.

The max-compute profile (`T2_PROFILE=max`, 10,000 resamples) gives identical skills (+0.0994, +0.1114; the model
has no tuned parameters) with CIs [+0.060, +0.140] and [+0.077, +0.144]; see `reports/modeling/24h/max/`.

## Caveats

- The winter-2024 fold is scored against the **recomputed** AQI (no official
  2024 label exists), so its absolute errors include reconstruction noise; the
  winter-2025 fold is scored against official AQI.
- Only two folds are possible with labelled data (2024, 2025); the mean ± std
  over two folds is indicative, not a stable variance estimate.
- The 24h target is a heavily smoothed series, so persistence remains a strong
  baseline; these numbers should be read as "small but real", not "large".
