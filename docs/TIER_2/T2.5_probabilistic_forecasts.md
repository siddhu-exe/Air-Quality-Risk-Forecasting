# T2.5 — Probabilistic / quantile forecasts and calibration

**Goal:** ship intervals and an exceedance probability instead of a single point
forecast, and honestly measure whether they are calibrated.
**Status:** done. Corrected script run in Colab on 2026-10-10; results below come from
`reports/modeling/probabilistic/` (pre-audit numbers are listed at the end as superseded).

## What was built

`src/models/train_quantile_forecast.py` (scikit-learn `HistGradientBoosting`, no LightGBM):

1. Quantile regressors for `target_aqi_24h` at α = 0.1 / 0.5 / 0.9. The number of
   boosting iterations is chosen on **validation pinball loss** via `staged_predict`;
   calendar on/off is chosen on summed validation pinball loss. Quantile crossing is
   removed by sorting.
2. **Split-conformal (CQR)** widening of the 80% interval using the finite-sample
   quantile level `ceil((n+1)(1−α))/n` on validation.
3. A persistence-band baseline interval (`aqi_curr` plus the empirical 10–90% training
   residual quantiles, with the same conformal pad) so interval width and coverage have a
   reference; interval widths and
   pinball loss are reported on test.
4. A classifier for `P(AQI ≥ 401)` with iterations chosen on validation **Brier**, a
   persistence-based probability, a constant-rate probability, a bootstrap CI on the
   Brier difference, and a reliability diagram (`reliability_severe.png`).

### What the audit changed

| Problem in the first version | Fix |
| :--- | :--- |
| Default early stopping used an internal **random** hold-out from time-ordered training rows (neighbouring hours leak), so iteration counts were not chosen chronologically. | `early_stopping=False`; iterations chosen on the chronological validation window. |
| Conformal pad used a plain percentile, not the finite-sample level. | Finite-sample CQR level. |
| Raw coverage was reported without interval width, so "coverage" could be bought with a huge interval. | Widths reported, plus a persistence-band baseline at the same nominal level. |
| The Brier comparison had no uncertainty and no constant-rate reference. | Bootstrap CI on Brier(model) − Brier(persistence) and a constant-rate Brier. |
| The reliability table was a CSV only. | Reliability plot for the model and the persistence probability. |
| No embargo. | 24h embargo before validation. |

Reliability (`reliability_severe.png`): in the lowest bin the classifier predicts a mean 0.037 but 14.6% of those

## Interpretation

- **The conformal step does what it promises on validation (0.800) and only partly on test (0.761).** The
  remaining gap is the covariate shift between a calm Sep–Oct window (2.4% severe hours) and the Nov–Dec winter
  (41.1%), which a validation-calibrated pad cannot see.
- **The quantile model's interval is not better than a trivial persistence band.** On test the persistence band is
  narrower (118.8 vs 142.0) and also covers more (0.780 vs 0.761). The learned model adds a median forecast that
  beats persistence by 6% but not the Ridge hybrid point forecast (MAE 34.02), so for intervals the persistence band is
  the baseline to beat, and it has not been beaten.
- **The severe-exceedance probability ties with persistence.** The Brier difference CI contains zero, so the
  earlier claim that the model is worse than persistence (0.205 vs 0.196) no longer holds after fixing the
  early-stopping leakage, but there is no evidence that it is better either. Both are far better than the
  constant rate.
- **The dangerous error is under-forecasting in "safe" bins.** A third of the winter test rows get a forecast below 0.1
  although 15% are severe. Any live alerting should either recalibrate on recent winter data or keep the
  persistence-based probability as the floor.

More tuning gave a slightly narrower interval but test coverage did not improve, the median skill fell, and the severe
classifier is now behind persistence (CI still contains zero). The classifier's chosen model stopped at 39 iterations,
a sign of fitting the calm validation window. The accepted (standard) results above are unchanged.
