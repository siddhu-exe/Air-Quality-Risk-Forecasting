# T2.3 — Forecast raw PM2.5 as an additional target

**Goal:** add a target with real hourly dynamics so model skill over persistence
becomes visible (the AQI target is a 24h rolling average with lag-1
autocorrelation ≈0.998, where persistence is nearly unbeatable).
**Status:** done. Corrected script run in Colab on 2026-10-10; results below come from
`reports/modeling/pm25/` (the pre-audit numbers are listed at the end as superseded).

## What was built

- `src/features/build_features.py` emits `target_pm25_{1,6,24}h` (`pm25.shift(-h)`)
  next to the AQI targets.
- `src/models/train_pm25_forecast.py` trains scikit-learn
  `HistGradientBoostingRegressor` models per horizon on the extended 2024–2025
  feature matrix. Splits, the 24h embargo and the calendar-feature list come from
  `src/models/splits.py`: train 2024-01-01..2025-08-31 (rows in the last 24h dropped),
  val 2025-09-01..10-31, test 2025-11-01..12-31.
- Persistence is `pm25_now`; skill = 1 − metric_model / metric_persistence, with a
  95% day-block bootstrap CI on the MAE skill.

### What the audit changed

| Problem in the first version | Fix |
| :--- | :--- |
| Raw/cyclical calendar columns were silently fed to a tree model (the project had removed them from the AQI model because trees cannot extrapolate across seasons). | Calendar on/off is a **validation-selected** variant, per horizon. |
| Only the `level` target form was tried; at 24h that is the form most exposed to winter regime shift. | Four variants per horizon (`level` / `residual` × calendar on/off); the residual form predicts PM2.5(t+h) − PM2.5(t) and adds it back to persistence. The variant with the lowest **validation** MAE is kept. |
| Training rows from the last 24h before validation had labels inside the validation window. | 24h embargo (`training_rows`). |
| No uncertainty on the skill; only validation/test point values. | Day-block bootstrap CI on skill; `variant_selection.csv` shows every variant's validation MAE so the choice is auditable. |
| Test could be read for every variant. | Test is scored **once**, for the selected variant. |

> `lightgbm` is not installed in the local venv, so scikit-learn histogram gradient
> boosting is used everywhere (the Colab notebook does the same, so local and Colab
> numbers agree).

## Interpretation

- **1h and 6h PM2.5 forecasts clearly beat persistence.** Test MAE skill is +0.20 (1h) and +0.37 (6h)
  with intervals far from zero. This is the first place in the project where a model has a large,
  unambiguous edge over persistence.
- **24h PM2.5 does not beat persistence in the test winter.** The selected model won on validation
  (+0.12) but its test skill is −0.09 with a CI of [−0.22, +0.01], i.e. it is at best indistinguishable
  from persistence. The validation window (Sep–Oct, persistence MAE 35.9) is much calmer than the winter test
  window (persistence MAE 75.3), so a 24h model fitted on mostly non-winter hours does not transfer.
- **Choices matter at the margin and are made on validation.** The residual target (predict the change,
  add it to persistence) is best at 1h and 24h; calendar features help 6h and 24h on validation.
  Calendar columns are a risk for trees in a season never seen in validation, so the 6h/24h
  choice should be re-checked when a second validation winter exists.
- **Compared with the earlier local pre-audit run** (+0.192 / +0.368 / −0.063), test skill moved by +0.01, +0.01 and
  −0.03, so the conclusions did not change; the audit mainly added the CIs, the embargo and the evidence that the 24h
  result is a genuine non-improvement, not an artefact of the variant.
- The PM2.5 skill does not transfer to the AQI target: AQI is a 24h average, so this is a complementary
  result, not an improvement of the AQI forecast.

### Max-compute check (`T2_PROFILE=max`, Colab, 2026-10-10)

Source: `reports/modeling/pm25/max/`. For the selected variant a 10-config random search (default config always a
candidate) chose hyper-parameters and boosting iterations on validation MAE; 10,000 bootstrap resamples. Test scored once.

| Horizon | Val MAE standard → max | Test MAE skill standard → max | Max test skill 95% CI |
| :--- | :---: | :---: | :---: |
| 1h | 13.239 → 13.061 | +0.2013 → +0.1991 | [+0.176, +0.221] |
| 6h | 25.543 → 25.238 | +0.3735 → +0.3762 | [+0.330, +0.419] |
| 24h | 31.620 → 31.266 | −0.0929 → −0.0899 | [−0.216, +0.016] |

The search lowered validation MAE by 1–2% in every horizon, but test skill did not move beyond the intervals and the 24h
model still does not beat persistence. The same variants were selected. The accepted (standard) results above are unchanged.

### Superseded (pre-audit script)

Test MAE skill +0.195 (1h), +0.374 (6h), −0.077 (24h) from a Colab run of the old code (no embargo, no
variant selection, no CI), and +0.192 / +0.368 / −0.063 from the earlier local run.

Note: the `smoke` profile (30 iterations) scored +0.053 at 24h on test. That is a lucky tiny model on one winter, not
evidence of an edge, and it was not used for any selection.
