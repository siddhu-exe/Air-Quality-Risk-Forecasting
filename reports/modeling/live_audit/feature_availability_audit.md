## Baseline reconciliation with Tier 2 (24h, validation)

The audit baseline reproduces Tier 2's stored frozen-model validation predictions (max absolute difference per row 0.000000); the audit refuses to run otherwise. Same frozen imputer, scaler and Ridge; no embargo or refit is involved because nothing is trained.

| Row set | Rows | Model MAE | Persistence MAE | Skill |
| :--- | ---: | ---: | ---: | ---: |
| Tier 2 stored frozen predictions, all validation rows | 9,590 | 29.024 | 30.708 | +0.0548 |
| Audit baseline (rebuilt features, frozen model), same rows | 9,590 | 29.024 | 30.708 | +0.0548 |
| Audit baseline, strict: label also inside the validation window | 9,422 | 28.454 | 29.935 | +0.0495 |
| Tier 2 EXTENDED model (trained with 2024 data; a different model), all rows | 9,590 | 28.795 | 30.708 | +0.0623 |

The strict row set drops the last day of October (issue times 2025-10-31, labels on 2025-11-01), which is the hardest day in the window; the default row set keeps it, as Tier 2 did. Its labels are the first test-window day.

Scenario definitions:

- `baseline`: all station inputs, as trained
- `openaq_filled`: OpenAQ primary; no solar anywhere, no ITO weather; gaps filled from Open-Meteo
- `openaq_unfilled`: OpenAQ primary; the same gaps left empty
- `datagovin_filled`: data.gov.in primary; NOx missing, weather from Open-Meteo
- `datagovin_unfilled`: data.gov.in primary; NOx and weather all missing
